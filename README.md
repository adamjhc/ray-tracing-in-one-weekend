# Ray Tracing In One Weekend

This is a Rust implementation of Peter Shirley's "Ray Tracing in One Weekend". Currently this implementation covers the [first](https://raytracing.github.io/books/RayTracingInOneWeekend.html) and [second](https://raytracing.github.io/books/RayTracingTheNextWeek.html) books.

## Extra features

- [x] Parallelised rendering using `rayon`
- [x] Progress bars
